# Practice 07: Conditionals

## নিয়ম এক নজরে

| Type | কখন | গঠন |
|---|---|---|
| Zero | সবসময় সত্য | If + present, present |
| First | বাস্তব সম্ভাবনা (ভবিষ্যৎ) | If + present, will + V1 |
| Second | কাল্পনিক (বর্তমান) | If + past, would + V1 |
| Third | অতীতে যা ঘটেনি | If + had + V3, would have + V3 |

⚠️ If-এর অংশে **will / would** বসে না।
⚠️ Second conditional-এ সব subject-এর সাথে **were**: If I **were** you…

**বাংলায় চেনার উপায়:**
- "…লে …ব" (পেলে যাব) → First
- "…তাম" (থাকত, করতাম), এখনকার কল্পনা → Second
- "…তাম", কিন্তু অতীতের কথা, যা ঘটেনি → Third

## Part A: অনুবাদ করো

**Zero**
1. পানি ১০০ ডিগ্রিতে গরম করলে ফোটে।
2. দেরিতে ঘুমালে আমার সকালে ক্লান্ত লাগে।

**First**

3. কাল বৃষ্টি না হলে আমরা পার্কে যাব।
4. প্রতিদিন practice করলে তোমার English ভালো হবে।
5. Scholarship পেলে আমি জার্মানিতে যাব।
6. তুমি দেরি করলে আমি তোমাকে ছাড়াই চলে যাব।

**Second**

7. আমি পাখি হলে আকাশে উড়তাম।
8. আমার আরও সময় থাকলে আমি একটা নতুন ভাষা শিখতাম।
9. আমি তোমার জায়গায় থাকলে চাকরিটা নিতাম।
10. আমি প্রধানমন্ত্রী হলে শিক্ষাখাতে আরও বিনিয়োগ করতাম।

**Third (অতীত, যা ঘটেনি)**

11. আমি আরও পড়লে পরীক্ষায় ভালো করতাম।
12. তুমি আমাকে বললে আমি তোমাকে সাহায্য করতাম।
13. ওই বাসটা miss না করলে আমি সময়মতো interview-তে পৌঁছাতাম।

**Unless**

14. পরিশ্রম না করলে তুমি সফল হবে না।

## Part B: সঠিক রূপ বসাও

1. If I ___ (get) the job, I will move to Dhaka.
2. If she studies hard, she ___ (pass).
3. If I ___ (be) rich, I would buy a house.
4. If he had more money, he ___ (travel) more.
5. If I ___ (know) earlier, I would have helped you.
6. If you ___ (heat) ice, it melts.
7. If it rains, we ___ (not / go) out.
8. If I ___ (be) you, I would apply now.
9. If they had left earlier, they ___ (not / miss) the flight.
10. What ___ you ___ (do) if you won the lottery?

## Part C: ভুল খুঁজে ঠিক করো

1. If I will get 7, I will be happy.
2. If I would have money, I would buy a car.
3. If I had studied, I would pass.
4. If it will rain, I will stay home.
5. If he come, I will tell him.
6. If I am you, I would study more.

## Part D: নিজের sentence লেখো

1. IELTS-এ ভালো score পেলে কী কী করবে? (first, ৩টা sentence)
2. অনেক টাকা থাকলে কী করতে? (second, ২টা sentence)
3. অতীতে কোনো সিদ্ধান্ত ভিন্নভাবে নিলে কী হতো? (third, ২টা sentence)
4. একজন বন্ধুকে পরামর্শ দাও: "If I were you, …"
